متجر Joya store (PHP)
=====================

التشغيل على استضافة مجانية (مثل InfinityFree أو 000webhost أو أي استضافة PHP):
1) ارفع محتوى هذا المجلد كله إلى مجلد htdocs أو public_html.
2) افتح رابط موقعك: يظهر المتجر.
3) لوحة التحكم: رابط-موقعك/admin  (كلمة السر المرسلة لك في المحادثة).
4) تأكد أن مجلدي data و uploads قابلان للكتابة (الصلاحية 755 أو 775).

الإعدادات (config.php): رقم الواتساب، الشحن، الشحن المجاني، كلمة السر.
لتغيير كلمة السر: شغّل الأمر التالي وضع الناتج في admin_hash
  php -r "echo password_hash('كلمتك', PASSWORD_DEFAULT);"

المتطلبات: PHP 7.4 أو أحدث. إضافة GD تصغّر الصور تلقائيا (اختيارية).
لا تحتاج قاعدة بيانات: البيانات في مجلد data بصيغة JSON.

مهم: ملفات .htaccess تحمي data و uploads على خوادم Apache.
إذا كانت استضافتك Nginx فاطلب من الدعم منع الوصول المباشر لمجلد data.
